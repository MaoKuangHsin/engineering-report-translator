# Engineering Report Translator

Turn engineers' technical notes into a short, manager-ready report — in English (default), Traditional Chinese, and Japanese.

## What it does

- Paste engineers' notes, one item per line — technical terms and English notes are fine
- It sorts them into: one-line summary for your manager, what was completed, key results (with numbers), business impact, issues and risks, and next steps
- Translates jargon (latency, bug, refactor, etc.) into business language
- Choose the audience (direct manager / senior leadership / cross-team / client) and format (weekly report / one-page slide / email / 1:1 update)
- Output language: English, 繁體中文, 日本語, plus English + Traditional Chinese and English + Japanese bilingual modes
- One-click copy or download as .txt
- Includes a 15-term glossary and a "what + number + impact" reporting cheat sheet, with examples in all three languages

## Use it

Open `index.html` in a browser — no build step, no server, nothing to install.

## Built with

A single self-contained HTML file.
